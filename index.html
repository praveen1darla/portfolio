Designed and developed a custom ROS2-based autonomous navigation architecture for a mobile rover using 3D LiDAR perception. Unlike traditional navigation stacks, this system was architected and integrated from scratch by combining 3D point cloud mapping, localization, path planning, collision checking, and autonomous navigation into a unified workflow.

Custom 3D LiDAR Navigation Architecture

Architected and developed a complete autonomous navigation framework for a ground rover using ROS2, LIO-SAM, OctoMap, and EKF sensor fusion. The system enables the rover to perceive, understand, and navigate complex environments using real-time 3D spatial information.

  • Designed a custom navigation architecture instead of relying only on pre-built frameworks.
  • Integrated LIO-SAM for high-accuracy 3D LiDAR SLAM and map generation.
  • Built the pipeline from 3D point cloud acquisition to mapping, localization, planning, and navigation.
  • Implemented EKF-based sensor fusion for stable pose estimation.
  • Generated 3D occupancy maps using OctoMap for environment understanding.
  • Developed custom collision detection and navigation decision-making modules.
  • Enabled autonomous waypoint navigation with RViz2 visualization and debugging.
